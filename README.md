# Junxi Tan

Software Engineering undergraduate at **Guangdong University of Finance and Economics**, expecting to graduate in June 2027.

I study how to make LLM systems easier to evaluate, more reliable when using tools, and more efficient under memory and compute constraints. My work combines controlled experiments with working systems and traceable evidence.
